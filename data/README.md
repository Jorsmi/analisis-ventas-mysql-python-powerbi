# Datos

El notebook espera estos cuatro archivos en esta carpeta:

| Archivo | Filas | Columnas |
|---|---|---|
| `clientes.csv` | 300 | id_cliente, nombre, email, ciudad, segmento, fecha_registro |
| `productos.csv` | 150 | id_producto, nombre, categoria, subcategoria, precio, costo, stock |
| `pedidos.csv` | 3,000 | id_pedido, id_cliente, fecha, estado, canal |
| `detalle_pedido.csv` | 7,503 | id_detalle, id_pedido, id_producto, cantidad, precio_unit, subtotal |

Los datasets fueron provistos por el programa de capacitación y no se incluyen en el repositorio.
